- 在独立目录准备固定提交的 gd_cubism / godot-cpp，复用本机已有的 Godot 4.7.2、匹配导出模板和官方 Native 5-r.5 SDK。
- 从源码编译 debug / release 原生插件、两个 C# 辅助程序，完成 Godot 导入与 Windows 导出。没有借用已发布程序的插件二进制来代替源码编译。
- 69 项登记素材的 SHA-256 保持一致。28 份贴图导入设置随清单同步，保留缩小采样、透明边缘和资源 ID。

- **47 项回归通过**，包含行为、文件处理、消化、小游戏、计分板、窗口、眩晕拖拽与松手恢复。真实鼠标状态检查在松开按键、无输入干扰时单独复核通过。

这次发布仅公开源码和许可文档；原有 0.2.0 游玩包、旧版兼容发布及更新接口不变。源码构建的容器元数据可能不同，因此以素材哈希、功能回归和画面对照判断一致性，不承诺构建出的 EXE / PCK 字节完全相同。

本次实际构建验证使用 `setup.py` 的本地引擎 / SDK 复用选项；自动下载引擎分支包含官方 SHA-512 校验，但未在本次验证中重新下载整套模板。
