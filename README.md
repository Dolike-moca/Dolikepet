# Dolikepet · Dolike 桌宠

**制作一个更有陪伴感的实用小桌宠。**

希望你在工作、学习或休息时，桌面上能有一只会走动、会撒娇、也会回应你的小猫。Dolikepet 把日常陪伴、互动小游戏和文件投喂放在一起，让整理不再需要的文件，也成为照顾猫咪的一部分。

当前版本：**beta0.1.0 · Windows 64 位 · 公开测试版**

[下载游玩版](https://github.com/Dolike-moca/Dolikepet/releases/tag/beta0.1.0) · [查看版本记录](https://github.com/Dolike-moca/Dolikepet/releases) · [反馈问题与建议](https://github.com/Dolike-moca/Dolikepet/issues)

## beta0.1.0 可以做什么

| 功能 | 和猫咪一起做的事 |
| --- | --- |
| 日常陪伴 | 看着鼠标、在桌面走动、坐下休息；拖动和抛起时，会有相应的表情与动作反馈。 |
| 文件投喂 | 把不再需要的文件拖进坩埚，猫咪靠近后会拿着文件图标，一口一口吃掉。 |
| 饱食与消化 | 自定义吃饱容量和消化时间，吃饱后休息，饿了再继续吃。 |
| 坩埚互动 | 召唤饭盆、举手够锅、落锅碰撞和救走后的感谢，让投喂多一点互动。 |
| 接猫挑战 | 抛起猫咪，碰到屏幕边缘后接住，挑战更高的连击和分数。 |
| 桌面设置 | 调整活动习惯、大小与位置，使用共享托盘入口，并在设置中检查更新。 |

## 开始陪伴

1. 在 [beta0.1.0 发布页](https://github.com/Dolike-moca/Dolikepet/releases/tag/beta0.1.0) 的 **Assets** 中下载 `Dolikepet-beta0.1.0-windows-x64.zip`。
2. 完整解压，打开 `Dolikepet` 文件夹，双击 **`DolikePet.exe`**。
3. 右键猫咪，或右键系统托盘里的猫咪图标，打开设置和饭盆。

游玩版无需安装 Godot、Python 或 Live2D 编辑器。请把解压后的程序文件放在一起；分享或移动时，移动整个文件夹。

| 操作 | 效果 |
| --- | --- |
| 按住猫咪拖动 | 移动猫咪；带着速度松手可以抛起它。 |
| 在猫咪上滚动滚轮 | 调整猫咪大小。 |
| 右键猫咪 / 托盘图标 | 打开设置、显示或收起饭盆、恢复大小位置、退出桌宠。 |
| 拖动坩埚 | 移动饭盆；松手后会下落。 |
| 双击坩埚 | 打开“猫的饭盆”文件夹。 |
| 把文件拖进坩埚 | 将文件移入饭盆，等待猫咪取食。 |

## 猫的饭盆与胃袋

**投喂会移动文件；消化到期会永久删除文件，不进入回收站。请只投喂确认不再需要的文件。**

首次启动时，程序目录中会自动创建“猫的饭盆”和“猫的胃袋”。文件会经历这样的过程：

**放入饭盆 → 猫咪靠近取食 → 吃完移入胃袋 → 达到消化时间后删除**

- 饭盆里的文件按放入的先后顺序取食，只有锅足够近时，猫咪才能吃到。
- 文件总大小越大，锅里的绿色浓汤越满；满锅容量可以用 MB / GB 自定义。
- 吃饱容量也可以用 MB / GB 设置。猫咪吃饱后会闭眼笑，用气泡说“吃饱了”，然后暂停进食和伸手够锅。
- 饱食度低于 **50%**，且剩余容量能容纳下一份食物时，才会恢复进食。
- 每份食物从移入胃袋时开始计时，消化时间可按小时设置；退出程序期间的时间也计入，下次启动时处理已到期的文件。
- 饥饿而饭盆未打开时，猫咪会用气泡请求开锅，也可以在设置中开启“桌宠自动打开锅”。

右键菜单能查看当前饱食度；设置页可以打开饭盆和胃袋文件夹、调整容量及消化时间。

## 和坩埚玩一会儿

打开饭盆时，猫咪会闭眼笑着举起双手，念出“出来吧，我的锅锅”。坩埚先从屏幕顶部冒出来，再从猫咪上方落下。

你可以及时把猫咪拉开；成功躲过后，它会用笑脸和“谢谢喵”回应你。锅落到头上会弹开，猫咪也会作出相应反应。平时把锅举到够不着的位置，它会举手晃动、跳跃，用气泡喊“我的饭盆，我的饭盆”。

这些互动包含嘴型开合、表情切换和睁眼过渡。猫咪吃饱休息时，会先安心休息，等饿了再继续够锅。

## 接猫挑战

把猫咪抛向屏幕的**上、左、右边框**，反弹后接住，挑战就会自动开始。

- **基础分：**一次抛出碰边 1 / 2 / 3 次，接住后分别得到 **+1 / +4 / +9**，按本次碰边次数的平方计分。
- **连击奖励：**连续接住达到 10 / 20 / 30……次时，分别额外得到 **+10 / +20 / +30……**。基础分和连击奖励分开显示，连击越高，数字效果越明显。
- **继续挑战：**接住后需在 3 秒内再次抛出。超时或没有接住，本轮分数清零，最高成绩保留。

屏幕右下角的小窗口会显示得分、连击和最高成绩。倒计时剩 1 秒时开始渐隐，结束后再过 1 秒完全透明并关闭。

## 按你的习惯设置

猫咪可以“常走动”“多待着”或“不乱动”，也能设置无互动后自动坐下休息的等待范围。视线跟随、置顶、自动下落等选项同样可以调整。

猫咪和坩埚共用一个系统托盘图标，正常游玩时不占任务栏按钮。设置是独立窗口，最小化设置页不会卡住猫咪，重新打开还能继续编辑未保存的内容。

## 获取更新

**右键猫咪 → 桌宠设置 → 版本与更新 → 检查更新**

发现新版本后，点击“查看并下载新版本”前往 GitHub。更新前先退出桌宠，再替换程序文件；**保留原目录里的“猫的饭盆”“猫的胃袋”及其中数据**。

个人设置和最高成绩保存在 `%APPDATA%\Godot\app_userdata\Dolike 桌宠`。同一 Windows 账号下的不同游玩目录共用这些设置，各自目录中的食物分别保存。
