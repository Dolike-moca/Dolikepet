# Dolike 桌宠

当前版本为 **0.3.1 · 色孽的赐福**：[GitHub 下载与更新说明](https://github.com/Dolike-moca/Dolikepet/releases/tag/0.3.1)。本次修复从设置更改大小后，坩埚画面冻结在旧尺寸、右侧和底部被裁切的问题。保存设置时跳过未改变的置顶属性；真正切换置顶时恢复本来可见的自有窗口，保持原窗口、透明度和动作，不误打开隐藏的饭盆或计分窗。回归覆盖七档体型、重复保存、置顶切换及隐藏后重开；原有素材和动作保持一致。本次修复已通过 245 项可见窗口检查，且 720 帧原有效果对比一致。

当前本地体型采用 **50%、75%、100%、125%、150%、175%、200%** 七档，**300 像素 = 100%**。设置常用页选择并保存，滚轮放大和缩小每次只改变一档；旧的非档位尺寸首次加载时归入最近档位。放大时蘑菇直接召唤到手中，双手抱稳、闭眼分五小口吃完后闪三次白光、平滑长大；缩小平滑过渡。滚轮连续滚动不会累积目标：等待或缩放动画期间忽略额外滚动，动画结束且停滚后，再次滚动才改变下一档；设置选择仍可直接指定比例，忙于拖拽、下落、眩晕、进食或小游戏时延后，交互仍优先响应。脚底中心保持稳定，边缘按屏幕范围收回。蘑菇不进入文件进食队列。验证记录见 [五口蘑菇与双向单档缩放](docs/review/mushroom-embrace/validation.json)；已整理为 0.3.0「色孽的赐福」更新，详见[发布页](https://github.com/Dolike-moca/Dolikepet/releases/tag/0.3.0)。

本地设置页采用 **B＋C**：680×540 独立窗口，侧栏分为常用、活动、喂食、关于；说明按需展开，普通设置无需滚动。常用页提供大小、视线和置顶，喂食页保留饱食度、容量、消化时间和两个文件夹入口，到期永久删除提示始终可见。修改仅在保存后应用，取消不应用，最小化再打开保留草稿。验证记录见 [精简设置页](docs/review/settings-compact/validation.json)；此项已整理为 0.3.0「色孽的赐福」更新，详见[发布页](https://github.com/Dolike-moca/Dolikepet/releases/tag/0.3.0)。

项目希望制作一个更有陪伴感的实用小桌宠，将日常陪伴、文件投喂和互动小游戏带到桌面上。面向玩家的项目介绍与玩法文案维护在 [公开 README](docs/public/README.md)。

源码工程、工程版和精简版均在启动约 5 秒后自动检查更新，之后每 6 小时检查；有新版本自动后台下载，猫咪分别提示发现新版和下载校验完成。设置页提供进度、重试、打开下载文件夹。接口和维护流程见 [更新说明](docs/UPDATES.md)。公开仓库包含源码、正式运行素材和构建工具；自有代码 MIT，项目美术 CC BY 4.0，第三方内容保留原许可。

此前版本的公开下载、更新检查、独立目录启动及动作画面核验，见 [0.2.1 发布核验](docs/review/0.2.1/validation.json) 与 [0.3.0 发布核验](docs/review/0.3.0/validation.json)。

双击 `启动桌宠.cmd`（或 `Start-Godot-Pet.cmd`）运行正式版。发布程序位于 `Runtime`，无需 Cubism 或 Godot 编辑器。

精简游玩包位于工作区的 `Dolikepet` 文件夹，双击其中的 `DolikePet.exe`。该包只包含 3 个必要运行文件、游玩说明和许可文件，保留自动更新、颠锅、计分板、眩晕互动、蘑菇体型动画和本次显示修复。饭盆与胃袋在首次启动时自动创建；同一 Windows 账号下共用桌宠设置。打包工具为 `tools/package-playable.ps1`，只复制并核验已发布的 Runtime，目标必须是新目录；不复制用户食物。独立目录启动核验见 [精简包记录](docs/review/playable-minimal.json)。

beta0.1.0 的接猫挑战渐隐效果见 [渐隐更新记录](docs/review/catch-score-fade/validation.json)。当前工程版已升级为回合结束后 5 秒隐藏，鼠标悬停平滑恢复不透明，双击打开独立计分板，可查看历史、明细与各游戏最高成绩，见 [计分板 C](docs/SCORE_BOARD_C.md)。

工程版的 [猫猫颠锅](docs/JUGGLE_B3.md) 使用 B3 眩晕布娃娃动作与 C 渐进物理：拖动猫咪用头接锅自动开始，偏心顶撞带动锅自然旋转，移动猫咪可传递动量。越玩弹得越高，高速锅的概率和速度逐渐提高；停转蓄力只在外轮廓发绿光。撞边次数平方计分，高速锅动作分乘 7，并显示「慈父的赐福」。首次落地结算后，锅轻弹后按剩余惯性滚动，平缓减速至底部向下停稳；不重新加速或强行补圈，低动能时仅缓慢回正。计分窗 5 秒后隐藏。这些更新已随 0.2.0 同步到 `Game/Runtime`、精简游玩包与 GitHub。

工程版已统一桌宠和锅的拖拽松手处理，补齐漏收松开、鼠标捕获转移、窗口失焦与隐藏时的释放，保持原有抛接惯性和动画。见 [拖拽松手修复](docs/DRAG_RELEASE.md)。

右键菜单保留猫的饭盆、视线跟随、置顶、桌宠设置、恢复大小位置和退出。设置中可以打开饭盆文件夹和猫的胃袋，调整饭盆满载量、吃饱容量、每份食物消化小时数，以及自动开锅。

饭盆里的文件按加入先后取食；只有锅足够近时才吃。吃完移入胃袋，吃饱后休息，低于 50% 才恢复取食。胃袋中的文件达到消化时间后永久删除，关闭程序的时间也计入。`猫的饭盆` 和 `猫的胃袋` 是用户数据，不属于可清理的程序缓存。

饭盆松手下落砸中头顶时，低处使用拖拽同款的短促挤眼反应，高处使用现有落地眩晕。落差越大，锅向旁边弹得越远，眩晕从 3 秒平滑增加至最多 6 秒；锅落地轻弹一次后摇稳。动作、触发阈值和回归说明见 [B2 撞击反馈](docs/BOWL_IMPACT_B2.md)。

## 维护

本项目从 2026-10-24 起统一按方案 C 维护，见 `docs/PROJECT_STANDARD.md` 和上级 `AGENTS.md`。

本次整理的验证结果与体积记录见 [最终审核](docs/FINAL_AUDIT.md)，动作对照视频见 [整理前后对照](docs/review/C-before-after.mp4)。

- 素材只编辑 `assets/library`；`assets/manifest.json` 记录当前正式素材与摆放信息。
- 总分层素材：`DesktopPet.Psd`。Cubism 工程：`model/source/DesktopPet.cmo3`。
- Godot 开发工程：`Godot/project.godot`；`Open-Godot.cmd` 打开编辑器。
- `Godot/tools/launch.ps1` 启动开发版；`--dev` 开启表情、喂食、站坐及重新加载演示菜单。
- `tools/manage.py sync` 同步素材；`tools/manage.py check` 核对哈希；`tools/manage.py psd` 生成总 PSD。
- `tools/test-release.py` 执行维护中的回归；`tools/build-release.ps1` 先构建到 `_work/release`。通过视觉核验后用 `-Publish` 发布已核验的同一份程序。
- 工具依赖放在上级 `_tools`，日志和预览帧放在 `_work`，历史方案仅在 `_archive`。

需要 Python 3.12 与 `psd-tools`、Pillow、numpy（可放上级 `_tools/psd-lib`），以及 `_tools/runtime/godot-build` 中固定版本的 Godot 和导出模板。素材同步、发布和回归均不依赖旧 `feat` 或历史缓存。

桌宠与坩埚共用通知区入口，常态不显示任务栏按钮；设置是独立窗口，最小化不暂停桌宠，重新打开保留未保存草稿。右键菜单底部显示实时饱食度条与百分比。详见 [窗口与通知区说明](docs/DESKTOP_SHELL.md)。
