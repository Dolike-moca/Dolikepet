Dolikepet 0.4.0 · 奸奇的赐福 · 精简游玩版

制作一个更有陪伴感的实用小桌宠。

0.4.0 更新
新增 AI 聊天：DeepSeek API、OpenAI API、ChatGPT 账户，简洁气泡、逐字回复与说话嘴型。
新增分层记忆、主动关心和可调语速；聊天闲置自然收起，打开聊天时暂停自主走动。
新增猫猫作息与坐姿睡眠，轻呼吸、自然睁眼，耳边有醒目的紫色 zzz。
优化设置布局、体型滑条、任务栏与聊天窗口切换；允许在全部食物都超出容量时吃一份大文件。
保留蘑菇进食、接猫挑战、颠锅和此前的缩放、拖拽修复。

启动与操作
完整解压后双击 DolikePet.exe，无需安装 Godot、Python 或 Live2D 编辑器。
EXE、PCK 和 DLL 必须放在一起。拖动猫咪移动，带着速度松手可抛起；滚轮按档位缩放。
右键猫咪或系统托盘图标可打开设置、饭盆、计分板和退出。
设置为独立窗口；猫咪和坩埚共用托盘图标，正常游玩时不占任务栏按钮。

体型与蘑菇
体型有 50%、75%、100%、125%、150%、175%、200% 七档，300 像素为 100%。
在设置“常用”页拖动体型滑条选择档位并保存，或在猫咪身上滚动鼠标滚轮。滚轮放大和缩小每次只改变一档。
放大时猫咪抬手，蘑菇在手上出现，双手抱着、闭眼分五小口吃完后闪三次白光并长大；缩小时平滑变小。
等待或缩放动画期间的额外滚动不会累积；动画结束且停滚后，再次滚动才改变下一档。
忙于拖拽、下落、眩晕或小游戏时会等动作结束，设置中仍可直接选择目标比例。
蘑菇是体型动画道具，不占饱食度，也不会操作饭盆或胃袋中的文件。

AI 聊天
右键 → 桌宠设置 → AI，选择 DeepSeek API、OpenAI API 或 ChatGPT 账户。
API 页面提供申请密钥的链接；ChatGPT 使用系统浏览器登录授权，可重新登录或删除本机账户记录。
AI 默认关闭，需启用并保存自己的连接。ChatGPT 能否使用取决于账户资格和实际授权。
右键“打开猫咪小对话框”开始聊天，Ctrl+Enter 发送，Enter 换行。气泡“…”可查看完整记录、记忆和设置。
五档语速同时控制文字出现和嘴部开合。打开聊天时猫咪暂停自主走动，关闭后恢复。
闲置后自动收起：普通内容 30 秒、长回复 60 秒、未发送草稿 120 秒，再用 3 秒淡出。
等待回复、文字显示或输入法组字时暂停计时；操作窗口可恢复清晰，草稿和聊天记录保留。
设置窗口打开时先提示暂时不能聊天；关闭设置后可正常打开。

人设、记忆与主动陪伴
默认角色「東菱可」，自称猫猫，默认称呼你“大人”；喜欢薯条、美食和战锤，可调整称呼与说话风格。
“陪伴与隐私”可开启休息提醒、闲聊与游戏后问候；五档“常说话”滑条调节频率。
每日次数支持无上限，静默时段可关闭；仍会避让忙碌状态，不连续打断互动。
可开启自动记忆日常聊天，并为记忆整理单独选择 AI。每天空闲时最多整理一次新增用户发言。
记忆分近期、长期、固定：普通内容会随时间遗忘，稳定事实在不同日子反复提及可成为长期记忆；固定记忆不自动遗忘。
可以查看、编辑、固定或删除记忆。自动摘要尽量简短，合并同类内容，减少重复输入。
聊天、连接测试、主动问候和记忆整理会使用所选服务的用量，程序不提供共享密钥，不自动切换计费账户。
自动整理会把有限的新用户发言和既有记忆摘要发给所选 AI；不会读取屏幕或发送饭盆、胃袋的文件名与内容。
配置、聊天与记忆在 %APPDATA%\Godot\app_userdata\Dolike 桌宠\ai-companion；密钥与账户令牌由 Windows 加密保存。
登录 ChatGPT 不会导入它的原有聊天与记忆。不开 AI 也能玩桌宠、小游戏、投喂和睡眠。

猫猫作息
设置 → 活动 → 猫猫作息，可调整自动睡觉、睡觉时间及三档日常小睡频率。默认时段 23:00–08:00。
平时无互动一段时间后可能坐下小睡，随机睡 3～8 分钟自然醒。
睡觉时段内更容易入睡，没人打扰就持续睡到时段结束；起止时间相同表示全天。
右键可选“睡觉”或“叫醒猫猫”。点击、拖拽或主动聊天也会叫醒；鼠标经过或在其他软件工作不会打扰她。
睡着时暂停走动、取食和主动问候，保留互动响应。聊天、设置、进食、小游戏和物理动作期间避让入睡。

猫的饭盆与胃袋
首次启动会在程序目录创建“猫的饭盆”和“猫的胃袋”。
双击锅打开饭盆文件夹，也可以把文件直接拖进锅。设置中也有文件夹入口。
投喂会移动文件：猫咪按放入顺序取食，吃完后移入胃袋；消化到期后永久删除，不进入回收站。
请只投喂确认不再需要的文件。退出程序的时间也计入消化时间。
满锅容量、吃饱容量可用 MB / GB 设置；消化时间按小时设置。
猫咪只有靠近锅时才能吃；吃饱后休息，饱食度低于 50% 且容得下下一份食物时再继续。
例外：如果锅里所有文件都超过胃袋总容量，饱食度低于 50% 仍会按顺序吃一份。
例如胃袋 100 MB、最小文件 500 MB，仍可吃一份；按真实大小完整计入胃袋，显示 100% 并停止进食，直到符合恢复条件。
可设置自动开锅。手动召唤时，锅先从屏幕顶部冒出来，再从猫咪上方落下；及时拉开猫咪可得到感谢。

接猫挑战
把猫咪抛向上、左、右屏幕边框，反弹后接住，自动开始挑战。
一次抛出碰边 1 / 2 / 3 次，分别加 1 / 4 / 9 分，按本次碰边次数的平方计分。
连续接住每逢 10 / 20 / 30……次，另加 10 / 20 / 30……分。
接住后超过 3 秒未再抛出，或没接住，本轮结束，最高成绩和本轮记录保留。

猫猫颠锅
锅落地前，拖动猫咪用头接住锅即可开始。猫咪使用眩晕眼，四肢和尾巴随拖动自然摆动。
每次随机弹起，并随碰撞旋转；移动猫咪会给锅传递部分动量。
随着本轮持续，弹高、高速锅概率和发射速度逐渐提高。
特殊锅升高后悬停旋转，随机停止，沿锅底方向蓄力 0.8 秒后飞出；绿光只在锅的周围。
动作分 = max(1, 本次撞边次数²) × 高速倍率；普通倍率 1，高速倍率 7。
10 / 20 / 30……连击另加同等分数，连击奖励不乘 7。
成功顶回高速锅，加分后显示绿色“慈父的赐福”。
锅首次落地结束本轮，没有 3 秒再次操作限制。之后轻弹、按剩余惯性滚动并自然停稳。

游戏记录
两种游戏结束后，计分窗保留并渐隐，5 秒后隐藏。
鼠标移入计分窗会平滑恢复不透明；移出后重新计时。悬停不会延长接猫的 3 秒抛出期限。
双击计分窗，或从菜单打开“计分板”，查看最近游戏、逐次加分、曲线和各游戏最高成绩。

眩晕与拖拽
眩晕时再被锅砸中会低头下沉并延长时间，剩余时间最多 30 秒。
眩晕中拎起使用布娃娃式悬挂，松手和重新拎起不重置眩晕时间。
落地后若未恢复，继续坐地眩晕；时间结束后自然恢复。
保留此前对快速拖动误触对白、对白影响命中范围、松手后仍吸附鼠标等问题的修复。

检查与安装更新
启动后约 5 秒自动检查新版本，之后每 6 小时再次检查。
发现新版本会用文字提醒；有网时自动下载，断线后自动重试，下载及校验在后台完成。
文件大小和 SHA-256 校验通过后，猫咪会提醒下载完成。
右键 → 桌宠设置 → 关于，可查看进度、手动重试、打开下载文件夹。
设置分为常用、活动、喂食、AI、关于五页；详细规则可展开，修改后点击保存。
常用页可调整大小（300 = 100%）、视线和置顶；喂食页可打开饭盆与胃袋文件夹。
更新包位于 %APPDATA%\Godot\app_userdata\Dolike 桌宠\updates，与饭盆和胃袋分开。
不会自动安装或覆盖正在运行的程序。先退出桌宠，再解压更新包替换程序文件，保留饭盆、胃袋和个人设置。
个人设置和游戏记录也应保留。同一 Windows 账号下不同游玩目录共用设置与记录，各目录中的食物分别保存。
