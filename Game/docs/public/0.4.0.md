# 0.4.0「奸奇的赐福」

这一版让猫猫开始与你聊天、记住相处中的小事，也有了自己的睡觉时间。继续朝着「一个更有陪伴感的实用小桌宠」迈进。

## AI 陪伴

- 新增 **DeepSeek API、OpenAI API 和 ChatGPT 账户**三种接入方式。使用自己的 API Key，或在浏览器登录授权；支持连接测试、模型选择、ChatGPT 重新登录和删除本机账户记录。
- 默认人设为「東菱可」：呆萌、可爱、有些迷糊的混沌猫猫，自称「猫猫」，喜欢美食、薯条和战锤。用户称呼与说话风格可以调整。
- 日常聊天与右键打开的小对话框统一为简洁气泡，支持流式回复、继续回复和完整聊天记录。说话配合嘴型；五档语速同时调整文字出现速度与嘴部节奏。
- 可开启休息提醒、日常闲聊和游戏后问候。「常说话」用五档滑条调节，每日次数支持无上限，静默时段可单独关闭；仍避让拖拽、进食、小游戏、设置等忙碌状态。
- 聊天闲置会平滑淡出并关闭，保留草稿和记录；再次操作可恢复清晰。打开聊天时暂停自主走动，关闭后恢复。

## 记忆与熟悉感

- 增加**近期、长期、固定**三类记忆。日常聊天可自动提炼成简短事实，反复在不同日子提及的稳定内容逐渐成为长期记忆；久未提及的内容会淡忘，固定内容不自动遗忘。
- 可查看、编辑、固定或删除记忆，单独选择默认记忆 AI。每天空闲时最多整理一次新聊天，自动摘要尽量简短，合并同类内容，减少重复输入。
- 固定人设与相处记忆分开；开启自动记忆才收集新发言，不导入 ChatGPT 的原有记录。聊天记录和记忆存于本机。

## 坐下来，睡一会儿

- 新增坐姿睡眠：慢慢闭眼、坐下、轻轻呼吸，醒来时自然睁眼；紫色 **zzz** 会缓慢上浮淡出，已放大方便辨认。
- **设置 → 活动 → 猫猫作息** 可调整自动睡觉、睡觉时间和日常小睡频率。默认 **23:00–08:00**。
- 日常无互动时有概率小睡，3～8 分钟后自然醒；睡觉时段内更容易入睡，没人打扰就睡到时段结束。可点击、拖拽或聊天叫醒，也可从右键菜单控制睡觉与叫醒。
- 睡眠期间暂停走动、取食和主动问候，保留互动响应；鼠标经过和操作其他软件不会叫醒猫猫。

## 体验优化与修复

- 设置整理为常用、活动、喂食、AI、关于五页；体型、说话速度和主动聊天频率均使用档位滑条，详细说明按需展开。
- 修复设置打开时聊天框闪一下又关闭的问题：现在会先用气泡说明暂时不能聊天，关闭设置后再正常打开。
- 修复聊天窗口与走动暂停的状态衔接；自动收起后不会因保留草稿而一直阻止走动。完整聊天窗口连同标题栏一起渐隐。
- 补齐普通提示、感谢、吃饱与聊天的嘴部动画，说完自然恢复；说话不锁住拖拽等互动。
- 优化任务栏显示，猫咪与坩埚继续共用系统托盘入口，设置保留独立窗口。
- 调整大文件投喂：**当锅内所有文件都大于胃袋总容量时**，饱食度低于 50% 仍能按顺序吃一份；按真实大小完整计入胃袋，随后显示吃饱并休息。
- 保留七档体型、蘑菇进食、坩埚召唤、接猫挑战、猫猫颠锅及此前的缩放和拖拽修复。

## 下载与更新

下载 **`Dolikepet-0.4.0-windows-x64.zip`**，完整解压后运行 **`Dolikepet/DolikePet.exe`**。适用于 Windows 64 位，无需安装 Godot、Python 或 Live2D 编辑器。GitHub 自动生成的 Source code 压缩包用于查看源码，不是游玩包。

旧版会按原有机制检查更新，有网时后台下载，校验通过后用文字提示。程序只自动下载，不自动安装：**先退出桌宠，再替换程序文件，保留“猫的饭盆”“猫的胃袋”和本机个人数据。** `SHA256SUMS.txt` 可校验游玩包，`update.json` 为更新信息。

AI 默认关闭，需配置自己的连接；聊天、连接测试、主动问候与记忆整理会消耗所选服务的用量。ChatGPT 接入是否可用取决于账户资格与授权，不会自动切换计费账户。自动整理会向所选 AI 发送有限的新用户发言和已有记忆摘要；不会读取屏幕或发送饭盆、胃袋中的文件内容。

**文件投喂会移动文件，胃袋中的文件到达消化时间后会永久删除，不进入回收站。请只投喂确认不再需要的文件。** 退出程序期间的时间也计入消化时间。

玩法与设置见 [项目 README](https://github.com/Dolike-moca/Dolikepet#readme)，欢迎在 [Issues](https://github.com/Dolike-moca/Dolikepet/issues) 留下问题与建议。
